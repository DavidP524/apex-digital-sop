05 — Build Phases (Claude Code)

Run /web-mockup in Claude Code to start. The skill handles phases 1–2. Phase 3–5 is where builds commonly break — follow exactly.

Phase 1 — Information Gathering

Claude Code asks for: business name, description, niche, aesthetic preset, primary CTA, output folder. Always scaffold in C:\temp\[slug] first — never directly in Google Drive or paths with apostrophes.

Phase 2 — Plan Approval

Claude Code presents the full plan (sections, copy direction, design system, file structure). David approves before any code is written. This is non-negotiable.

Phase 3 — Scaffolding

# 1. Create temp build folder
mkdir -p /c/temp/[slug]
cd /c/temp/[slug]

# 2. Scaffold Vite React project
npm create vite@latest . -- --template react

# 3. Install Tailwind CSS v3 (NOT v4)
npm install -D tailwindcss@3 postcss autoprefixer
npx tailwindcss init -p

# 4. Install runtime deps
npm install gsap lucide-react

# 5. Install all deps
npm install

Phase 4 — File Writes

Write in this order: postcss.config.cjs → tailwind.config.js → index.html → src/index.css → src/main.jsx → src/App.jsx → all components.

Always use postcss.config.cjs with module.exports — never export default, even with "type": "module" in package.json.

All .btn-* and .card classes must be inside @layer components {} in index.css — otherwise inline-flex overrides Tailwind's hidden utility on mobile.

Phase 5 — Verification

# Kill any running node processes first
powershell -Command "Stop-Process -Name 'node' -Force"

# Start dev server
cd /c/temp/[slug] && npm run dev

# Preview via Preview MCP
# launch.json goes in Desktop/.claude/ — NOT the project folder
# Use preview_screenshot to verify all sections
# Scroll to bottom — GSAP hides elements at opacity:0 until scroll
# Use preview_eval to force ScrollTrigger refresh if needed

After visual verification: copy build to Desktop hub via PowerShell, then deploy to Vercel.

06 — Known Gotchas

Every item below has burned at least one build. Never skip reading this section.

1. Apostrophes in paths break bash
Paths like Daniel's Master Landscaping - Mock Up cause TAR_ENTRY_ERROR during npm install when the project is inside Google Drive. Always scaffold in C:\temp\[slug] first. Copy to final destination with PowerShell after the build is complete.
2. postcss.config.cjs must use module.exports
Even with "type": "module" in package.json, PostCSS config must be CommonJS: module.exports = { plugins: { tailwindcss: {}, autoprefixer: {} } }. Using export default throws SyntaxError: Unexpected token 'export'.
3. @layer components required for all custom classes
Any class using @apply inline-flex (like .btn-primary) must be inside @layer components {}. Otherwise Tailwind's hidden and md:block utilities cannot override it, causing the mobile CTA button to bleed through the navbar.
4. GSAP ScrollTrigger hides elements at opacity:0 until scroll
When verifying with Preview MCP screenshots, elements animated by ScrollTrigger appear invisible at the page bottom because scroll hasn't triggered them. Use preview_eval to call ScrollTrigger.refresh() or scroll the preview before screenshotting the lower sections.
5. Unsplash photo IDs — always visually verify
Photo ID descriptions in training data are wrong or out of date. A photo listed as "lush garden" may actually show a dining room, a person, or red poppies. Always take a screenshot of the gallery section and visually confirm every image. Replace any wrong ones before declaring done.
6. Preview MCP launch.json location
The launch.json file must live at C:\Users\DavidsPc\Desktop\.claude\launch.json (the session working directory), NOT in the project folder. Kill lingering node processes with powershell -Command "Stop-Process -Name 'node' -Force" before starting.
7. Tailwind CSS version — always v3
Install with npm install -D tailwindcss@3 postcss autoprefixer. Tailwind v4 has breaking API changes and is not compatible with this stack. Never upgrade without explicit instruction.
