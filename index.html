Qualification Matrix · Max 60 seconds per lead

A lead qualifies if it meets the baseline and any flaw

  • 20+ total reviews — baseline: proves cash flow and demand
  • Missing or broken website — automatic qualification
  • Poor mobile optimization — requires manual scaling/pinching
  • Missing "Call Now" CTA — complex forms or hidden numbers

Baseline required. Any one flaw advances the lead to outreach.

7-day Instagram warmup Before your first DM

Use a dedicated Instagram Business account. Engage organically with target accounts for one week before sending a single DM. Strict limit: 10–15 personalized DMs per day to avoid spam filters.

  • Day 1 — dedicated IG Business account live; profile complete (logo, bio, link)
  • Day 2 — follow 15–20 target niche accounts
  • Day 3 — like + comment on 5 target posts (authentic, not generic)
  • Day 4 — post 1 portfolio/work sample to your grid
  • Day 5 — engage with 5 more accounts, watch stories
  • Day 6 — post 1 more portfolio piece; keep engagement rhythm
  • Day 7 — first DM wave: send 10–15 personalized messages

Dead Lead Recycling Protocol Day 14 · 44 · 45 · 47

Highly qualified leads with 20+ reviews are not discarded. Move them through the recycling timeline:

  1. Day 14 — If no reply after 2 messages, move the lead to the "Cold" tab in the Deal Tracker.
  2. Day 44 (30 days later) — Feed the lead back into Gemini to re-verify website status.
  3. Day 45 — If the site remains broken, send a single, final seasonal touchpoint.
  4. Day 47 — If no reply, archive permanently.

Automated Invoice Engineering · Zero-Cost Stack

Google Workspace Stack

Master Template (Google Docs): A branded invoice template utilizing placeholders (e.g., {{client_name}}, {{amount}}). A Stripe or PayPal.Me payment link is permanently embedded.

Central Database (Google Sheets): The "Apex Deal Tracker".

Automation Engine (Google Apps Script): A script attached to the Sheet that duplicates the Doc, injects the data, converts it to a PDF, and emails it directly to the client via Gmail.

Apps Script · Invoice generator (template) 
function generateInvoice() {
  const sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  const row = sheet.getActiveRange().getRow();
  const data = sheet.getRange(row, 1, 1, sheet.getLastColumn()).getValues()[0];

  // Column mapping — adjust to match your Apex Deal Tracker schema
  const [clientName, email, amount, projectName, dueDate] = data;

  // Duplicate the master invoice template
  const TEMPLATE_DOC_ID = 'PASTE_DOC_TEMPLATE_ID_HERE';
  const INVOICE_FOLDER_ID = 'PASTE_FOLDER_ID_HERE';

  const template = DriveApp.getFileById(TEMPLATE_DOC_ID);
  const folder = DriveApp.getFolderById(INVOICE_FOLDER_ID);
  const copy = template.makeCopy(`Invoice — ${clientName} — ${projectName}`, folder);

  // Inject placeholders
  const doc = DocumentApp.openById(copy.getId());
  const body = doc.getBody();
  body.replaceText('{{client_name}}', clientName);
  body.replaceText('{{amount}}', `$${amount}`);
  body.replaceText('{{project_name}}', projectName);
  body.replaceText('{{due_date}}', dueDate);
  body.replaceText('{{invoice_date}}', new Date().toLocaleDateString());
  doc.saveAndClose();

  // Convert to PDF and email via Gmail
  const pdf = copy.getAs('application/pdf').setName(`Invoice — ${clientName}.pdf`);
  GmailApp.sendEmail(email, `Invoice — ${projectName}`, `Hi ${clientName},\n\nAttached is your invoice for ${projectName}. Payment link is embedded in the PDF.\n\n— David, Apex Digital`, {
    attachments: [pdf],
    name: 'Apex Digital'
  });

  SpreadsheetApp.getUi().alert(`Invoice sent to ${email}`);
}
